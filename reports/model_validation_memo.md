# Model Validation Memo

## Model purpose

Offline fixed-income market-risk model development and validation for synthetic corporate-credit and securitized-products proxy portfolios.

## Validation tests

Data-quality checks, benchmark comparison, VaR/ES calculations, stress testing, backtesting, assumption sensitivity, specialty ablation, and release gates.

## Model inventory

`outputs/model_inventory.csv` links each component to purpose, inputs, tests, limitations, and controls.

## Limitations

No proprietary data, no production deployment, no official regulatory capital certification.
